# **App Name**: Gepto Express

## Core Features:

- Location-Based Catalog: Display a geo-filtered list of grocery items based on the user's detected location in Cooch Behar.
- Shopping Cart & Checkout: Allow users to add items to a cart, apply promotions, and select a payment method for checkout.
- Order Tracking: Provide real-time updates on order status and location within Cooch Behar.

## Style Guidelines:

- Primary color: Gepto Green (#008000) for brand recognition.
- Secondary color: White (#FFFFFF) for clean interface.
- Accent color: Teal (#008080) for interactive elements and highlights.
- Clean and minimalist design to ensure ease of use.
- Simple, recognizable icons for categories and actions.
- Subtle micro-animations for button taps and loading states to enhance user experience.
